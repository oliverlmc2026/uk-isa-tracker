# 09: 安全匯入 JSON 備份

**What to build:** 用戶可以匯入先前匯出嘅 JSON 檔以還原資料或遷移去另一部裝置。匯入前先驗證檔案；格式錯誤、結構唔符或 schema 版本唔支援嘅檔案會被拒絕，並顯示清楚訊息，現有資料原封不動。驗證通過後，取代現有資料前要用戶明確確認。匯出再匯入之後，賬戶、Contribution 同設定要完全一致。
